# Qué es Victoria ERP

Victoria ERP es un sistema de gestión empresarial en la nube, modular y configurable, pensado para medianas empresas de Latinoamérica.

## Propuesta de valor

- Procesos de Compras y SCM con profundidad corporativa y operación simple.
- Localización nativa para Perú, Colombia, Panamá, El Salvador y Chile.
- Toda función disponible por API, lista para agentes de IA.
- Reportes armados por el propio usuario.
